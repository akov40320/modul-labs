# Порядок проверки заявки

Приоритет проверки заявки: email и количество проверяются до сохранения; ошибки обоих полей показываются вместе.

При отправке заявки проверяются корректность email и допустимое количество товара.
Если проверка не пройдена, интерфейс показывает ошибки и не сохраняет заявку.
Документ фиксирует согласованное правило для разработки и тестирования формы.
