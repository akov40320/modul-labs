# Glossary - глоссарий

| Термин | Значение в проекте |
|---|---|
| B2B | Продажи организациям и корпоративным заказчикам. |
| MVP | Минимальный набор функций, достаточный для демонстрации основного сценария. |
| Набор | Каталожная позиция конструктора с ценой, числом деталей и минимальной партией. |
| Категория | Направление набора: образование, корпоративные подарки или розница. |
| Партия | Количество одинаковых наборов в расчете заявки. |
| Квалифицированная заявка | Запрос с именем, компанией, email, набором и количеством; в MVP это только локальная запись. |
| User Story | Формулировка потребности пользователя по шаблону «Как..., я хочу..., чтобы...». |
| AC | Acceptance Criteria - проверяемое условие приемки. |
| WIP | Work In Progress - ограничение числа одновременно выполняемых задач. |
| Kanban | Метод управления непрерывным потоком задач по колонкам доски. |
| localStorage | Локальное хранилище браузера; в MVP не является серверной базой. |
| Feature-ветка | Изолированная Git-ветка для одной задачи. |
| CI/CD | Автоматические проверки, сборка и последующая доставка приложения. |
| DoD | Definition of Done - критерии готовности результата. |
