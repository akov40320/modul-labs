# CI/CD Pipeline - проектный план

Статус: **конфигурация и удаленная интеграция pending**. Файл описывает целевой процесс и не утверждает, что удаленный запуск уже был выполнен.

## Предлагаемая платформа

GitHub Actions для будущего GitHub-репозитория. До создания репозитория и секретов удаленный pipeline не запускается.

## Триггеры

- `push` в `main` и `develop` - CI;
- `pull_request` в `main` - CI;
- push в `main` после успешного CI - условный CD.

## Шаги CI

1. Checkout.
2. Установка Node.js.
3. Установка зависимостей.
4. `npm run lint`.
5. `npm test` - минимум три проверки базовой логики.
6. `npm run build`.

## Шаги CD

После CI можно подключить выбранный хостинг (например, статический хостинг) и секрет deploy token. До выбора хостинга URL и имя секрета не заданы. Секреты нельзя хранить в этом каталоге.

## Проверки ветки

Для `main` планируется запрет прямого push и требование успешного CI перед merge. Настройка выполняется только владельцем реального репозитория.

## Доказательства

Для отчета после реального подключения потребуются скриншоты: защита ветки, неуспешный PR, успешный PR, workflow с CI/CD и публичная страница. В текущем локальном комплекте таких скриншотов и URL нет.
