# Onboarding - локальный запуск

## Что нужно

- Windows или macOS/Linux;
- Node.js версии, совместимой с `package.json`;
- браузер с включенным JavaScript;
- папка проекта `Готовые лабораторные/project`.

Пароли, токены, приглашения и доступы к внешним сервисам в этом документе не хранятся и не выдавались.

## Локальный сценарий

1. Открыть папку `Готовые лабораторные/project`.
2. Установить зависимости командой `npm install` (если они появятся в проекте).
3. Запустить проверки: `npm run lint` и `npm test`.
4. Собрать проект: `npm run build`.
5. Открыть локальный файл/сервер согласно инструкции проекта и проверить якоря, каталог, фильтры и заявку.
6. Для очистки демонстрационных данных открыть раздел «Учебный кабинет» и удалить заявки или очистить данные браузера.

## Правила данных

- Использовать только вымышленные данные.
- Заявка из локального MVP не отправляется в CRM и не покидает браузер.
- `hello@modul.example` - демонстрационный адрес домена `.example`, не канал связи.
- Внешние сервисы подключаются только после отдельной настройки и проверки доступа.
