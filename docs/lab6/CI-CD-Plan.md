# ЛР6 - CI/CD план

Цель: воспроизводимо проверить, собрать и затем доставить статическое приложение.

## Локальный минимум

- `npm run lint`;
- `npm test` (не менее трех базовых unit-проверок);
- `npm run build`.

Если команда отсутствует в текущем checkout, это отдельная задача подготовки проекта, а не доказательство успешного CI.

## Удаленная конфигурация

Целевой файл: `.github/workflows/ci-cd.yml` в будущем удаленном репозитории. Пример шагов приведен в `лр6/CICD.pdf` и пересказан в [Wiki CI/CD](../wiki/CI-CD-Pipeline.md). Создание workflow, секретов и деплоя ожидает remote.
