# Инструкция публикации в Яндекс Формах

Это **план действий**, а не подтверждение публикации. Учетная запись, организация и URL формы не предоставлены.

1. Войти в нужную организацию Яндекс 360 с реальным владельцем доступа.
2. Создать новую форму и назвать ее «Получить коммерческое предложение - Модуль».
3. Добавить поля в порядке из `form-spec.json`; обязательность и ограничения перенести вручную.
4. Добавить текст учебного режима и не запрашивать лишние персональные данные.
5. Настроить сообщение успешной отправки без обещания реальной обработки.
6. Провести пробную отправку только с вымышленными данными.
7. Проверить доступ по ссылке и права просмотра ответов.
8. Записать фактический URL в отчет только после реальной публикации.

**Текущий результат:** внешний URL и скриншоты не созданы; значение `external_url` в JSON равно `null`.
