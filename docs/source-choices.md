## Обязательные поля задачи по методичке ЛР2

Источник: `лр2/8a327fc4b2aeb86014e97577f69d0dac.docx`.

1. **Детали задачи:** тип, приоритет, метки, окружение, версия исправления.
2. **Блокер/дефект:** описание, предусловия, что случилось, шаги воспроизведения, фактический результат, ожидаемый результат, примечания.
3. **Доработка:** описание, User Story по форме «Как [роль], я хочу [действие], чтобы [ценность]».
4. **Критерии приемки:** проверяемые условия в формате «Дано + Когда + Тогда».
5. **Дополнительные материалы:** макеты/дизайн, API, аналоги, документация.
6. **Нефункциональные требования:** устройства (десктоп/мобильные/все) и изменения бэкенда/API.
7. **Связи и подзадачи:** связи с задачами; подзадачи для аналитики, бэкенда, фронтенда, тестирования, UX/UI, документации и DevOps с назначением исполнителя.

Файл `lab2/backlog.csv` повторяет эти поля для каждой записи. Состав и ответственность приведены в [Team](wiki/Team.md). Технический assignee GitHub — доступный аккаунт akov40320; роли задач отражаются отдельным полем.
