# Лабораторные работы 1–6 по проекту Модуль

В комплекте шесть отчётов Word, рабочее приложение, документация, макеты, бэклог, локальная доска, Git-история и конфигурация GitHub Actions.

## С чего начать

1. Отчёты находятся в папке `Отчёты`: отдельный документ для каждой работы.
2. Чтобы открыть приложение на этом компьютере, запустите `Запустить приложение.cmd` и перейдите по адресу, который появится в окне. Окно сервера должно оставаться открытым.
3. Документация и схемы доступны через [страницу материалов](docs/index.html). Их исходники находятся в `docs`.
4. Исходный код — в `project/app`. Команды запуска, сборки и проверок описаны в [README проекта](project/README.md).

## Что требует подключения сервисов

Выбран локальный вариант выполнения без внешних аккаунтов. Для выполнения именно онлайн-пунктов исходных заданий остаётся:

- отправить промпты в Алису AI и опубликовать форму/лендинг в Яндексе;
- создать организацию Яндекс 360, подключить Трекер, пригласить реальных участников и перенести карточки/доску;
- создать общий GitHub-репозиторий и доступы, включить защиту main;
- выполнить реальные Pull Request с падающим и проходящим CI, настроить GitHub Pages и проверить публичную ссылку;
- вести доску в течение семестра и получить реальное командное review/утверждение макетов.

Локальные изображения и журналы показывают только фактически выполненные проверки. Они не являются скриншотами Яндекс Трекера или GitHub.

## Бесплатные инструменты

Исходники, локальные проверки и документы не требуют платных сервисов. Личные Яндекс Формы, чат с Алисой AI и создание лендингов в Директе бесплатны. Публичный GitHub-репозиторий позволяет использовать бесплатную защиту ветки, стандартные Actions runners и GitHub Pages.

Текущая официальная справка Яндекс Трекера описывает платные тарифы. Для всех шести работ без оплаты потребуется доступ вуза, действующее специальное предложение либо согласованная преподавателем замена Трекера.
